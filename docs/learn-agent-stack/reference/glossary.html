Agent Stack Glossary

praxstack/block-buzz · reference

Agent stack
The curated set of skills, workflows, MCP servers, and Cloud Agent scripts that turn this Buzz fork into an agent-first development environment.
Skill
A SKILL.md file under .cursor/skills/ that teaches Cursor how to perform a specialized task (review, TDD, research, etc.).
Persona
A role-voice prompt (e.g. FRONTEND-PE) under docs/agents/personas/. Complements skills with tone and perspective, not full methodology.
Workflow prompt
Paste-ready goal text under docs/agents/workflows/praxstack/ (e.g. high-end-operator). Invokes installed skills by name.
gstack
Review/ship/compound-engineering skill family. Use for code review, landing PRs, and post-ship learning loops.
pstack / poteto-mode
Planning and execution orchestration. One methodology per task — do not combine with competing orchestrators.
praxstack
Personal skill/persona portfolio (constellation-team, spec-creator, high-end-operator workflows).
Hermit
Pinning toolchain manager. Activate with . ./bin/activate-hermit before Rust/Node/Flutter commands.
Cloud Agent environment
Cursor-managed VM defined by .cursor/environment.json, Dockerfile, and install/start scripts.
OpenSpec
Spec-driven change workflow. Proposals live under openspec/ when used.
Graphify
Code graph tool for structural navigation. Installed via install-repo-intelligence.sh.
Context7 MCP
MCP server for up-to-date library documentation. Requires CONTEXT7_API_KEY.
One methodology per task
Rule: pick one planning/review orchestrator per session. Stacking kingmode + gstack + superpowers causes context rot.
Buzz-native skills
Fork-specific skills in .agents/skills/ (desktop-screenshot, sprout-cli). Symlinked into .cursor/skills/.
skills-lock.json
Manifest tracking vendored skill versions for reproducible installs.
