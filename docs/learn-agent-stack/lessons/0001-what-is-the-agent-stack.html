Lesson 0001: What Is the Agent Stack?

Estimated read: 10 minutes

The one-sentence version

The agent stack is everything in this fork that helps AI agents (and you) build Buzz reliably: pinned toolchain, Cloud Agent VM scripts, 380+ Cursor skills, and workflow prompts that chain those skills into discover → spec → plan → build → review → ship.

Three layers

1. Runtime environment

Docker, Postgres, Redis, Hermit-pinned Rust/Node/Flutter, relay and desktop build deps.

scripts/cloud-agent-install.sh   # once per snapshot
scripts/cloud-agent-start.sh     # every boot
.cursor/environment.json         # wires install + terminals

2. Skills library

Specialized instructions the agent reads when invoked. Installed to .cursor/skills/.

./scripts/install-agent-skills.sh      # gstack, wshobson, superpowers, …
./scripts/install-praxstack-skills.sh  # constellation-team, personas

3. Workflows and personas

Human- or agent-pasted prompts that orchestrate skills for a lifecycle phase.

docs/agents/workflows/praxstack/high-end-operator/
docs/agents/personas/praxstack/md-personas/

Rules that prevent pain

  • One methodology per task. Do not load multiple orchestrators.
  • Activate Hermit first. . ./bin/activate-hermit
  • Buzz product code ≠ agent stack. Upstream CI (desktop E2E) can flake independently of skill changes.
  • Save Cloud Agent environment in Cursor Portal after validating install.
